# for-sri

An 8-page surprise site: hero → letter → promises → photo gallery → quotes → gift → song → closing. Monkey-themed, since she loves them 🐒

## Before you run it
1. Her 4 photos are already in `public/photos/` (1.jpg–4.jpg). Replace them or edit captions in `src/App.jsx` (`PHOTOS` array) any time.
2. Add your own copy of the song to `public/audio/`, named `kannana-kanne.mp3` — I can't bundle the actual audio file myself since it's copyrighted.

## Run locally
```
npm install
npm run dev
```
Open the printed local URL (usually http://localhost:5173).

## Go live
```
npm run build
```
This creates a `dist/` folder — deploy it with Vercel or Netlify (see chat for step-by-step).
